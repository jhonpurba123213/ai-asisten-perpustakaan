# Panduan Penggunaan AI Asisten Perpustakaan Kampus

## 1. Deskripsi Aplikasi
AI Asisten Perpustakaan Kampus merupakan aplikasi berbasis web yang dikembangkan menggunakan Streamlit untuk membantu mahasiswa memperoleh informasi perpustakaan dan mencari koleksi buku.

## 2. Teknologi yang Digunakan
- Python
- Streamlit
- Ollama
- Qwen 2.5:3B
- MySQL
- ChromaDB
- Retrieval-Augmented Generation (RAG)

## 3. Fitur Aplikasi
1. Dashboard Perpustakaan
2. Chat AI
3. Cari Buku
4. Rekomendasi Buku
5. Kelola Buku
6. Upload PDF
7. Jam Operasional Perpustakaan
8. Informasi Perpustakaan

## 4. Cara Menjalankan Aplikasi
1. Pastikan Python sudah terinstal.
2. Pastikan Ollama sudah terinstal dan model Qwen 2.5:3B tersedia.
3. Jalankan MySQL melalui XAMPP.
4. Buka folder proyek melalui Visual Studio Code.
5. Instal dependensi menggunakan perintah:

   `pip install -r requirements.txt`

6. Jalankan aplikasi menggunakan perintah:

   `streamlit run app.py`

7. Buka browser dan akses:

   `http://localhost:8501`

## 5. Catatan
Aplikasi saat ini dijalankan secara lokal menggunakan komputer pengembang. GitHub digunakan untuk menyimpan kode sumber dan dokumentasi proyek.
